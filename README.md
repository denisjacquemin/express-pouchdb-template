# Commands
## Start server in DEBUG mode

./src$ DEBUG=myapp:* npm start

## Build the Docker image with BuildKit
./$ COMPOSE_DOCKER_CLI_BUILD=1 DOCKER_BUILDKIT=1 docker-compose build

## Run the image
./$ docker-compose up
